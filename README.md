# 🚢 Ferry Ticket Demand Forecasting System

This project predicts short-term ferry ticket demand using Machine Learning and Time-Series Forecasting techniques. The system helps improve ferry scheduling, crowd management, and operational planning through predictive analytics.

The dashboard was developed using Streamlit and includes:
- Interactive visualizations
- Future demand forecasting
- KPI monitoring
- Feature importance analysis
- Confidence interval forecasting

Technologies Used:
Python, Pandas, Scikit-Learn, Streamlit, Plotly, Machine Learning
